# WORMVOLUTION!



An evolution simulator applying basic machine learning principles to demonstrate changing traits over time. 



### To Make:

use the make.bat file.

* In a terminal, navigate to the root directory (where this file is).
* Then simply type: "make".



### To Run:

use the run.bat file.

* After running the 'make' command simply type 'run'
* After running the 'make' command, run the resulting .jar executable file.



### Design:

Follows a loose MVC model. See the flowchart in this directory. Main.java is the controller in this framework and is the root of the program.
